# 学习仓库智能导入（形态 A + B 自动检测）

## 目标
让导入器识别学习型仓库的两种典型形态，走不同解析路径，保留文件夹结构作为课程结构，让每个课时有真实正文内容。

## 两种形态的检测策略

| 形态 | 检测信号 | 解析方式 |
|------|---------|---------|
| **A 课程型** | 有 lessons/ 目录 或 顶层有 ≥3 个数字命名文件夹（`1-Intro`、`2-NeuralNets`） | 文件夹=章节，文件夹内 README.md=课时正文，ipynb/quiz=配套练习标记 |
| **B 单文件型** | 不满足 A，但 README.md > 5KB（有实质内容） | 走现有 parseMarkdownToCourse（H2→章节 H3→课时）|
| **降级** | 都不满足（纯链接集合仓库如 ossu） | 提示用户"这不是学习仓库，无法导入" |

## 实施步骤

### Step 0: live 验证（先跑再写码）
用 Node fetch 验证 jsDelivr API 能拉到 4 个真实仓库（AI-For-Beginners / ML-For-Beginners / system-design-primer / Awesome-FDE-Roadmap）的文件树结构，确认 response shape + 目录/文件统计。

### Step 1: 新建 `src/main/services/pure/repo-fetcher.ts`（纯函数，fetchFn 注入）
- `listRepoFiles(owner, repo, fetchFn)` → jsDelivr 主路径，返回 `{files: [{path, size}], source}`
- `detectRepoPattern(files)` → 返回 `"course" | "single-file" | "unsupported"`，含检测理由
- `fetchMarkdownContents(paths, owner, repo, fetchFn, onProgress)` → 5 并发批量拉 .md 原文，返回 `{ok, failed}`
- `buildCourseFromRepoTree(files, mdContents)` → 按检测结果走两条路径：
  - course 模式：文件夹结构映射成 section/lesson，正文取自文件夹内 README.md，ipynb 记为 labType
  - single-file 模式：找最大 README.md，走 parseMarkdownToCourse

### Step 2: 扩展 `course-generator.ts`
- 新增 `generateCourseFromRepoFiles(db, sections, opts)` — sections 已含每个 lesson 的 sourcePath（真实文件路径）+ content（正文 body），写入 content_nodes 时不再硬编码 README.md

### Step 3: 改造 `course:importFromRepo` IPC handler
- `registerCourseHandlers` 加 mainWindow 参数
- 流程：解析 owner/repo → listRepoFiles → detectRepoPattern → 如果 unsupported 报友好错误 → fetchMarkdownContents（发 import:progress）→ buildCourse → generateCourseFromRepoFiles
- 保留原单 README 拉取作为网络 fallback

### Step 4: registerAllHandlers 传 mainWindow

### Step 5: ImportView.tsx 加进度显示
- 订阅 import:progress，busy 时显示"拉取文件 3/12: docs/api.md"

### Step 6: 修复种子课程
- seed.ts 内嵌 FDE README 全文（已拿到 53KB），走 generateCourseFromMarkdown，每个 lesson 有真实 content

### Step 7: 新建 `scripts/verify-repo-fetcher.mjs`
注入 fake fetchFn 测：三种 pattern 检测、course 模式解析、single-file 模式解析、过滤规则、并发拉取、unsupported 报错

## 不做的事
- 不导入非学习仓库（纯项目仓库、链接集合仓库检测后拒绝）
- 不解析 ipynb 成可执行练习（只标记 labType，正文用 .md）
- 不改现有 parseMarkdownToCourse（复用，在外层适配）
- 不做 AI 内容增强（live test + 教学智能化的范畴）
