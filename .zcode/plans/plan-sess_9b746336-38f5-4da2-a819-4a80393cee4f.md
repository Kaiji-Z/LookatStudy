# BYOK 优化：引导按钮 + 自动迭代预设 + 精简配置入口

## 改动 1：未配 key 时显示引导按钮（而非内联 key 输入）

**ChatPanel.tsx**:
- 未配 key 时，消息区显示一个大号"⚙️ 配置 AI 模型"引导按钮
- 点击该按钮 → `setPanelMode("settings")` 切到设置 tab
- 删掉 ConfigGuide 内联组件（key 输入全部在设置页做）
- 输入区在未配 key 时只显示一行提示 + 按钮跳转

## 改动 2：预设数据全面更新（基于 research 的真实数据）

**llm-presets.ts** — 更新为研究确认的最新数据：

GLM（智谱）— 用户最常用的：
- 标准端点: `https://open.bigmodel.cn/api/paas/v4`
- CodingPlan 端点: `https://open.bigmodel.cn/api/coding/paas/v4`
- 模型更新为真实列表: glm-4.6(旗舰编码), glm-4-flash(免费), glm-4-long(1M上下文), glm-4.5-air(轻量)
- keyUrl 更新为 `https://open.bigmodel.cn/usercenter/proj-mgmt/apikeys`

DeepSeek:
- 模型: deepseek-chat, deepseek-reasoner（标注即将退役）, deepseek-v4-flash

新增预设:
- Moonshot Kimi: `https://api.moonshot.cn/v1`, kimi-k3
- Qwen 通义: `https://dashscope.aliyuncs.com/compatible-mode/v1`, qwen-plus/turbo/max
- SiliconCloud 硅基流动: `https://api.siliconflow.cn/v1`（聚合平台，一个 key 访问多个开源模型）
- OpenRouter: `https://openrouter.ai/api/v1`（国际聚合，覆盖所有主流模型）

每个预设增加字段:
- `docsUrl`: 官方文档链接
- `models[].free`: 标记免费模型
- `models[].capabilities`: ["chat", "reasoning"] 等能力标记

## 改动 3：OpenRouter 自动模型发现

**llm-client.ts** 新增 `fetchOpenRouterModels()`:
- 调 `GET https://openrouter.ai/api/v1/models`（公开，无需 key）
- 返回所有可用模型列表（含 context/pricing/capabilities）
- SettingsView 里加一个"🔄 刷新模型列表"按钮
- 结果合并到自定义 provider 的 models 下拉里

## 改动 4：verify-llm-presets 更新

测试覆盖新增的 provider 预设。

## 不做的事
- 不在 ChatPanel 里保留 ConfigGuide 内联输入（全部走设置页）
- 不做定时后台刷新（手动点"刷新"即可）
- 不接 Baidu ERNIE（非 OpenAI 兼容，需要 custom SDK）
