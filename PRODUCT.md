# LookatStudy — Product Definition

## What
Local-first AI learning platform. Turns GitHub learning repositories into Duolingo-style courses with AI tutoring, exercises, and spaced repetition. Electron desktop app, BYO LLM key.

## Who
Self-directed learners studying from open-source learning repos (e.g. Microsoft AI-For-Beginners, system-design-primer). People who find raw documentation hard to follow and want guided, interactive learning with progress tracking.

## Register
**Product** — design serves the task of learning. Familiarity is a feature. Earned trust, not surprise.

## Color strategy
**Committed** — Duolingo-inspired vibrant greens (#58cc02) on dark surfaces. The brand green carries primary actions, progress states, and active selections. Blue accent (#1cb0f6) for secondary interactions. Gold (#ffc800) for mastery/crowns. Dark-first (neutral-950 base) for focus.

## Typography
Single sans family (system-ui stack). Fixed rem scale. Tight hierarchy: lesson titles 1.25rem, body 0.875rem, labels 0.75rem. No display fonts — this is a tool, not a magazine.

## Key surfaces
1. **Skill tree** (right pane) — Duolingo-style vertical path of circular lesson bubbles with locked/available/in-progress/mastered states
2. **AI agent panel** (left pane) — chat + exercises + settings, tab-switched
3. **Dashboard** — mastery heatmap + stats
4. **Import view** — repo URL / markdown paste

## Motion
150-250ms transitions. Lesson bubbles scale on hover. Mode tabs slide. State changes only — no decorative choreography.
